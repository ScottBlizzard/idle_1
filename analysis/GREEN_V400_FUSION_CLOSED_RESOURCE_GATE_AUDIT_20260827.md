- **GO (descriptor resource-rebind closure scope):** the actual descriptor was bound one-way into a new TensorProgram resource formula, after which the resident plan was rebuilt against that rebound full-program hash. Executable nodes, the stable execution identity, packed blob bytes, and descriptor bytes were unchanged; the same descriptor then replayed successfully against the rebound program and rebound plan. This closes `source program/plan -> descriptor -> rebound program -> rebound plan` without circular hashes.
- **GO (canonical-zero correctness scope):** native MPFR zero endpoints are serialized canonically as significand zero and exponent zero, while the Python decoder independently short-circuits zero before exponentiation. This removes the pathological pre-v403 `0 * 2^-1073741823` decode without changing any mathematical value.
- **GO (observation-only):** the native packed affine ABI was exercised with every distinct actual affine weight/bias pair used by the 81-node program, including selected-width, attention, and both MLP projections, at 384 and 512 bits. Outputs remain synthetic and no scientific result is opened.
- **GO (observation-only):** the native row-batched LayerNorm ABI was exercised with all four distinct actual gamma/beta pairs used by the program at both precisions. The row-batched native GELU ABI is bit-identical to individually dispatched exact GELU jets and is exercised at both program widths 10 and 3072 with deterministic synthetic Jet2 inputs and the closed GPT-2 GELU constants.
- **GO (observation-only):** the compiled exact-fusion ABI was exercised at the actual width 768 for all four branch pairs at both precisions. A liveness-derived, no-static-cache kernel-only composition accounts for every affine, LayerNorm, GELU, per-head attention aggregate, and fused-contrast call required by the 81-node program, but is deliberately not treated as end-to-end timing or a formal bound.
- **GO (narrow native-buffer correctness scope):** an opaque native Jet2 buffer executes an actual-weight `768 -> 3072 -> 768` affine/GELU/affine MLP chain without intermediate JSON/FFI materialization and remains bit-identical to the existing per-node round-trip path at both precisions.
- **GO (resident attention correctness and observation scope):** the standalone JSON all-head ABI remains disabled because it was slower than per-head JSON calls. The opaque-buffer executor instead uses one all-head native call: eliminating Q/K/V JSON and twelve per-head crossings reduced single-run warm actual-shape observations from 24.0753 to 23.8464 s at 384 bits and from 26.8651 to 26.3172 s at 512 bits while preserving exact roots.
- **BLOCK:** the full 81-node *native dispatcher* is not implemented. Semantic node orchestration, liveness, and cache lookup still live in Python; static past-K/V native buffers are runtime cache objects rather than hash-closed resident-plan payloads; the fusion payload still uses a canonical-JSON control plane; and there is no single native plan-loader/dispatch entry point. This is now a resident-buffer Python dispatcher, not yet a closed native dispatcher.
- **BLOCK:** the current exact certificate snapshot is not the binding final certificate artifact. The certificate dataclasses still lack the separately serialized endpoint-evaluation radii, direct residual centers/radii, weight- and summation-rounding contributions, import/reduction/subdivision accounting, runtime parity diagnostics, complete backend/environment/commit provenance, and process-tree resource record required for formal closure.
- **BLOCK:** no numeric replacement cap is authorized. The observations are not formal wall-time bounds and exclude set/copy/comparison/serialization and full certificate orchestration.
- **BLOCK:** real certificate, development rows, confirmation rows, and scientific outcome access remain unauthorized.

## Remaining minimum gate

The next authorized work is the hash-closed native loader for the frozen descriptor, then a single native dispatch entry point with resident-plan ownership of static past-K/V payloads. The full frozen adaptive policy should be measured only after that outcome-blind execution path exists, because the current Python-dispatched path is already known to be resource-dominant. Binding certificate component accounting and process-tree rather than same-process peak memory must then be implemented and measured. Only after those components are hash-closed may a replacement numeric cap be proposed. A measured guardband must not be described as a formal runtime upper bound.
