# GREEN v3.0.0 Development Terminal Evidence Package

This directory contains the compact, self-verifying evidence package for the
post-corrigendum GREEN v3.0.0 development result.  The complete 122 MB transport
Parquet remains on the server and is identified by SHA-256 in
`POSTCORRIGENDUM_DIAGNOSTIC.json`; `dev_transport_scores_core.parquet` and
`dev_gate_scalar_audit.parquet` retain every row-level scalar used by the
terminal analysis without duplicating large nested prediction arrays.
