## 3. Why the previous certificate description was insufficient

The previous decision required an outward upper bound

\[
M_{2,r}(h)\;\ge\;\sup_{t\in[-h,h]}|\Psi_r''(t)|
\]

and a certified endpoint error \(\epsilon_{\psi,r}(h)\), but it did not define a sound enclosure algorithm for the actual Transformer computation. That omission was material for four reasons.

First, AD computes derivatives at selected floating-point points. It does not bound a derivative over an interval and it does not prove that a maximum was not missed. Second, separately boxing PAT, TAR, joint, and bypass runs destroys the strong deterministic correlation created by shared weights, residuals, and constants. Third, LayerNorm and softmax couple coordinates, so naive whole-network intervals widen rapidly. Fourth, a finite maximum over a grid remains a sampled lower bound on the true supremum, not an upper certificate.

A monolithic full-network interval/Taylor calculation is mathematically valid if all primitives are sound, but it is predictably too loose for the frozen path because it starts upstream of many shared operations, repeats nearly identical branches independently, and loses exact cancellation before the final four-way difference. It is therefore **not** authorized as the primary witness.

The replacement is a **primitive relational causal-cone certificate**:

1. cut the proof graph at the earliest frozen controlled hook whose stored tensor is already part of the v3/v4 row record;
2. import that tensor, every donor/control direction, every downstream weight, and every contrast coefficient as exact IEEE dyadic constants;
3. construct the exact downstream causal cone of the control parameter \(t\);
4. hash-cons the PAT/TAR and joint/bypass branches into one relational expression DAG;
5. cancel provenance-identical shared subexpressions before interval evaluation;
6. propagate outward interval jets for values, first derivatives, and second derivatives;
7. subdivide the one-dimensional domain deterministically;
8. certify endpoint remainders by a signed partitioned curvature identity, using global \(M_2\) only as a valid fallback and diagnostic.

This construction is proof-valid and materially tighter than independent full-network boxes. It does not assume that dependency inflation disappears; it detects and reports inconclusiveness when it remains too large.

## 4. Exact certified object

### 4.1 Frozen row record

For each admissible row \(r\), formal prepare must serialize a `JointWitnessRowSpec` containing, at minimum:

\[
\mathcal R_r=(\mathcal M,\mathcal T,\mathcal H_r,\mathcal A_r,\mathcal V_r,\mathcal C_r,\mathcal S_r),
\]

where:

- \(\mathcal M\) is the exact model/configuration identity, including TransformerLens version, model weight hash, tokenizer hash, architecture flags, normalization type, activation type, fold/centering/refactor flags, dtype provenance, and evaluation mode;
- \(\mathcal T\) is the exact tokenized input and attention-mask record for every branch;
- \(\mathcal H_r\) identifies every controlled hook, layer, token position, head or residual coordinate, and hook ordering;
- \(\mathcal A_r\) is the affine control insertion record for every condition and branch;
- \(\mathcal V_r\) is the exact final logit/contrast projection;
- \(\mathcal C_r\) contains PAT/TAR and joint/bypass branch identities and the exact differencing order;
- \(\mathcal S_r\) contains split membership, provenance hashes, sealed-set exclusion proof, and the unchanged v4 gate identity.

All floating-point tensors are imported by decoding their IEEE bit patterns. Decimal string round-tripping is forbidden. A finite float32, bfloat16, float16, or float64 value is treated as the exact dyadic rational represented by its bits. NaN and infinity are hard failures.

### 4.2 Affine control domain

The only free variable is a real scalar

\[
t\in I_h=[-h,h],\qquad h>0,
\]

where \(h\) is an exact, preregistered dyadic rational. For condition
\(c\in\{\mathrm{PAT},\mathrm{TAR}\}\) and branch
\(b\in\{\mathrm{J},\mathrm{B}\}\), the controlled hook tensor is

\[
A_{r,c,b}(t)=A^{0}_{r,c,b}+tD_{r,c,b}.
\]

`J` denotes the frozen joint path-control branch and `B` its frozen matched-bypass branch. A direction may be identically zero for a branch if and only if the frozen repository semantics require it. The exact affine insertion AST, including multiple hook writes and their order, is serialized and hashed. Any non-affine control, data-dependent hook selection, or dynamic branch is unsupported and requires another GPTPro decision.

### 4.3 Downstream causal cone

For each branch, let

\[
F_{r,c,b}:A_{r,c,b}(t)\mapsto z_{r,c,b}(t)
\]

be the exact frozen downstream Transformer computation from the earliest controlled hook to the final residual/logit tensor needed by the contrast. The causal cone contains every node reachable from a \(t\)-dependent hook value to the contrast. Off-cone tensors are frozen exact constants.

The cone rule is conservative and exact:

- a residual-stream perturbation at a token makes all coordinates of any subsequent LayerNorm at that token dependent, because mean and variance couple coordinates;
- an attention query perturbation affects all unmasked attention weights for that query;
- a key or value perturbation affects every later query that can attend to that key under the fixed causal mask;
- all residual additions, subsequent blocks, final LayerNorm, and unembedding/contrast nodes reachable from those values are included;
- reshapes, head splits, concatenations, slices, permutations, and hook identities preserve dependency tags exactly;
- a node may be removed only when exact graph reachability proves it is independent of \(t\), not because an empirical derivative is small.

The graph extractor must emit a complete operation list and prove, by forward dependency tagging, that every output dependency is accounted for. If the exact TransformerLens execution traverses an unsupported operation, certification stops with `UNSUPPORTED_PRIMITIVE`; the operation may not be approximated silently.

### 4.4 Four-branch scalar and differencing order

Let \(v_r\) be the exact frozen final contrast vector. Define

\[
C_{r,c,b}(t)=\langle v_r,z_{r,c,b}(t)\rangle.
\]

The matched-bypass effect within condition \(c\) is

\[
B_{r,c}(t)=C_{r,c,\mathrm J}(t)-C_{r,c,\mathrm B}(t).
\]

The certified Joint Witness scalar is

\[
\boxed{
\Psi_r(t)=B_{r,\mathrm{PAT}}(t)-B_{r,\mathrm{TAR}}(t)
}
\]

or, expanded,

\[
\Psi_r(t)=
C_{r,\mathrm{PAT},\mathrm J}(t)
-C_{r,\mathrm{PAT},\mathrm B}(t)
-C_{r,\mathrm{TAR},\mathrm J}(t)
+C_{r,\mathrm{TAR},\mathrm B}(t).
\]

This ordering is binding. The graph serializer must compare it against the actual repository-defined PAT/TAR and bypass ordering and stop on disagreement. If the frozen repository uses equivalent naming or stores the contrast before unembedding, the serializer may normalize names but may not change the algebra.

All four branches are represented in one hash-consed relational DAG. A subexpression is shared only when its operation, parameters, inputs, mask, token position, and provenance hashes are identical. Algebraic simplifications such as \(x-x=0\), collection of exact affine terms, and cancellation of a shared final branch are allowed only under exact DAG identity. Merely close numerical values may not be cancelled.

## 5. Outward interval-jet calculus

### 5.1 Interval representation and soundness invariant

An interval is a closed MPFR interval \(X=[\underline X,\overline X]\). Every lower endpoint is rounded toward \(-\infty\) and every upper endpoint toward \(+\infty\). Define

\[
\operatorname{mag}(X)=\max(|\underline X|,|\overline X|),\qquad
\operatorname{mid}(X)=\frac{\underline X+\overline X}{2},\qquad
\operatorname{rad}(X)=\frac{\overline X-\underline X}{2},
\]

with outward rounding for all reported values.

On a cell \(J=[a,b]\), an interval jet is

\[
\mathfrak J_J[x]=(X^{(0)},X^{(1)},X^{(2)}),
\]

with the invariant

\[
\forall t\in J:\quad
x(t)\in X^{(0)},\quad x'(t)\in X^{(1)},\quad x''(t)\in X^{(2)}.
\]

The control seed \(x(t)=x_0+td\) has

\[
X^{(0)}=[x_0,x_0]+J[d,d],\quad
X^{(1)}=[d,d],\quad
X^{(2)}=[0,0].
\]

A frozen constant \(c\) has \(([c,c],[0,0],[0,0])\).

### 5.2 Directed interval arithmetic

For \(X=[x_-,x_+]\) and \(Y=[y_-,y_+]\):

\[
X+Y=[\operatorname{RD}(x_-+y_-),\operatorname{RU}(x_++y_+)],
\]

\[
X-Y=[\operatorname{RD}(x_- - y_+),\operatorname{RU}(x_+-y_-)],
\]

and

\[
XY=[\operatorname{RD}(\min S),\operatorname{RU}(\max S)],
\quad
S=\{x_-y_-,x_-y_+,x_+y_-,x_+y_+\},
\]

where every candidate product is itself computed once under downward and once under upward rounding as needed. Reciprocal is allowed only when \(0\notin Y\):

\[
Y^{-1}=
\begin{cases}
[\operatorname{RD}(1/y_+),\operatorname{RU}(1/y_-)] & y_->0,\\
[\operatorname{RD}(1/y_+),\operatorname{RU}(1/y_-)] & y_+<0,
\end{cases}
\]

with the natural ordering of the two endpoints; division is multiplication by the reciprocal. Square uses the exact interval rule

\[
X^2=
\begin{cases}
[0,\operatorname{RU}(\max(x_-^2,x_+^2))] & 0\in X,\\
[\operatorname{RD}(\min(x_-^2,x_+^2)),\operatorname{RU}(\max(x_-^2,x_+^2))] & 0\notin X.
\end{cases}
\]

`min` or `max` is used only to construct an interval enclosure; no model-side data-dependent max is introduced.

### 5.3 General first- and second-derivative recurrences

For \(z=x+y\) or \(x-y\), derivatives are componentwise sums or differences.

For \(z=xy\):

\[
Z^{(0)}=X^{(0)}Y^{(0)},
\]

\[
Z^{(1)}=X^{(1)}Y^{(0)}+X^{(0)}Y^{(1)},
\]

\[
Z^{(2)}=X^{(2)}Y^{(0)}+2X^{(1)}Y^{(1)}+X^{(0)}Y^{(2)}.
\]

For \(z=x^{-1}\), with \(0\notin X^{(0)}\):

\[
Z^{(0)}=(X^{(0)})^{-1},
\]

\[
Z^{(1)}=-X^{(1)}(X^{(0)})^{-2},
\]

\[
Z^{(2)}=2(X^{(1)})^2(X^{(0)})^{-3}-X^{(2)}(X^{(0)})^{-2}.
\]

For a twice continuously differentiable scalar primitive \(z=f(x)\), with certified interval extensions \([f](X^{(0)})\), \([f'](X^{(0)})\), and \([f''](X^{(0)})\):

\[
Z^{(0)}=[f](X^{(0)}),
\]

\[
Z^{(1)}=[f'](X^{(0)})X^{(1)},
\]

\[
Z^{(2)}=[f''](X^{(0)})(X^{(1)})^2+[f'](X^{(0)})X^{(2)}.
\]

All vector, matrix, and tensor rules below are repeated applications of these identities, with shared subexpressions retained in the relational DAG.

### 5.4 Affine maps, einsums, and projections

For a frozen exact matrix \(W\) and bias \(b\),

\[
y=Wx+b,
\]

\[
Y^{(0)}=W X^{(0)}+b,\qquad
Y^{(1)}=W X^{(1)},\qquad
Y^{(2)}=W X^{(2)}.
\]

Each dot product is accumulated with directed MPFR fused multiply-add where available. Positive and negative coefficient contributions are accumulated separately before the final outward addition. The accumulation order is fixed by the serialized graph and is independent of outcomes.

This rule covers Q/K/V projections, MLP input/output projections, output projection, unembedding, and final contrast. A tensor contraction in which both factors depend on \(t\) uses the product recurrence term by term; it may not be treated as affine.

### 5.5 Residual addition, hook insertion, rearrangement, and slicing

Residual addition is componentwise addition of jets. Hook insertion is the exact affine seed in §4.2. Reshape, transpose, head split/merge, concatenation, slice, gather with frozen indices, and permutation copy the corresponding interval-jet entries without widening. A gather with a data-dependent index is unsupported.

Dropout must be disabled by `model.eval()` and must serialize as the identity. If any stochastic mask is active, the row is invalid.

### 5.6 Exponential, logarithm, square root, inverse square root, tanh, erf, and sigmoid

For monotone primitives, interval endpoints are evaluated with MPFR directed rounding. The derivative recurrences are:

#### Exponential

\[
\exp'(x)=\exp(x),\qquad \exp''(x)=\exp(x).
\]

Thus

\[
Z^{(1)}=Z^{(0)}X^{(1)},\qquad
Z^{(2)}=Z^{(0)}\bigl(X^{(2)}+(X^{(1)})^2\bigr).
\]

#### Logarithm

Require \(\underline X^{(0)}>0\):

\[
(\log x)'=x^{-1},\qquad (\log x)''=-x^{-2}.
\]

#### Square root

Require \(\underline X^{(0)}>0\):

\[
(\sqrt x)'=\frac{1}{2\sqrt x},\qquad
(\sqrt x)''=-\frac{1}{4x^{3/2}}.
\]

#### Inverse square root

Require \(\underline X^{(0)}>0\):

\[
f(x)=x^{-1/2},\quad
f'(x)=-\frac12x^{-3/2},\quad
f''(x)=\frac34x^{-5/2}.
\]

#### Hyperbolic tangent

With \(T=\tanh X\):

\[
f'(x)=1-\tanh^2x,
\qquad
f''(x)=-2\tanh x\,(1-\tanh^2x).
\]

The range of \(f''\) is enclosed by outward evaluation of this expression and, when a cell crosses a stationary point of \(f''\), by certified subdivision at a precomputed MPFR enclosure of that stationary point. Merely evaluating the two endpoints of a non-monotone derivative is forbidden.

#### Error function

\[
\operatorname{erf}'(x)=\frac{2}{\sqrt\pi}e^{-x^2},
\qquad
\operatorname{erf}''(x)=-\frac{4x}{\sqrt\pi}e^{-x^2}.
\]

The interval for the second derivative is obtained by expression propagation plus subdivision at its known stationary points, never by endpoint-only evaluation.

#### Sigmoid

With \(s=\sigma(x)\):

\[
s'=s(1-s),\qquad
s''=s(1-s)(1-2s).
\]

### 5.7 Exact frozen GELU

The graph extractor must read the actual TransformerLens activation identity. It must not substitute an “equivalent” GELU implementation.

For GPT-2 `gelu_new`/tanh-GELU, the certified primitive is the exact computation encoded by the frozen implementation constants:

\[
u(x)=\kappa(x+\lambda x^3),\qquad T(x)=\tanh u(x),
\]

\[
g(x)=\frac{x}{2}(1+T(x)),
\]

where \(\kappa\) and \(\lambda\) are imported from the exact IEEE constants used by the frozen code, not recomputed from a decimal formula. The derivatives are

\[
u'(x)=\kappa(1+3\lambda x^2),\qquad
u''(x)=6\kappa\lambda x,
\]

\[
T'(x)=(1-T(x)^2)u'(x),
\]

\[
T''(x)=(1-T(x)^2)u''(x)-2T(x)(1-T(x)^2)(u'(x))^2,
\]

\[
g'(x)=\frac12(1+T(x))+\frac{x}{2}T'(x),
\]

\[
\boxed{g''(x)=T'(x)+\frac{x}{2}T''(x).}
\]

These expressions are propagated as a shared DAG. If the model uses exact-erf GELU, the implementation must instead bind

\[
g(x)=\frac{x}{2}\left(1+\operatorname{erf}\frac{x}{\sqrt2}\right),
\]

\[
g'(x)=\frac12\left(1+\operatorname{erf}\frac{x}{\sqrt2}\right)+\frac{x}{\sqrt{2\pi}}e^{-x^2/2},
\]

\[
\boxed{g''(x)=\frac{2-x^2}{\sqrt{2\pi}}e^{-x^2/2}.}
\]

An activation identity other than the explicitly supported frozen one is a hard stop, not permission to use sampled derivatives.

### 5.8 LayerNorm

For a LayerNorm input \(x\in\mathbb R^d\), define

\[
\mu=\frac1d\sum_{i=1}^d x_i,
\qquad
c_i=x_i-\mu,
\]

\[
q=\epsilon_{\mathrm{LN}}+\frac1d\sum_{i=1}^d c_i^2,
\qquad
s=q^{-1/2},
\]

\[
y_i=\gamma_i c_i s+\beta_i.
\]

For LayerNorm variants without learned affine parameters, set \(\gamma_i=1\) and \(\beta_i=0\). The epsilon and affine parameters are exact frozen constants.

The exact recurrences are

\[
\mu'=\frac1d\sum_i x_i',\qquad
\mu''=\frac1d\sum_i x_i'',
\]

\[
c_i'=x_i'-\mu',\qquad c_i''=x_i''-\mu'',
\]

\[
q'=\frac2d\sum_i c_i c_i',
\]

\[
q''=\frac2d\sum_i\left((c_i')^2+c_i c_i''\right),
\]

\[
s'=-\frac12q^{-3/2}q',
\]

\[
s''=\frac34q^{-5/2}(q')^2-\frac12q^{-3/2}q'',
\]

\[
y_i'=\gamma_i(c_i's+c_is'),
\]

\[
\boxed{y_i''=\gamma_i(c_i''s+2c_i's'+c_is'').}
\]

The interval lower bound for \(q\) is computed from the sum-of-squares form, with each square interval clipped to its mathematically valid nonnegative lower bound. Consequently \(q\ge\epsilon_{\mathrm{LN}}>0\) in exact real arithmetic. If the serialized epsilon is not strictly positive, certification fails. The implementation must also apply the already-frozen exact LayerNorm structural envelope as an intersecting enclosure; the intersection may tighten the interval but may never discard a value allowed by either proof.

A whole-vector LayerNorm is evaluated jointly. Independently normalizing coordinate boxes and forgetting their shared mean/variance is forbidden.

### 5.9 Attention scores and softmax

For one head and query position \(i\),

\[
s_{ij}(t)=\frac{q_i(t)^\top k_j(t)}{\sqrt{d_{\mathrm{head}}}}+m_{ij},
\]

where the fixed causal mask is handled structurally: masked keys are omitted from the softmax domain and assigned exact weight zero. The implementation must never put \(-\infty\) into MPFR arithmetic.

The score derivatives are

\[
s_{ij}'=\frac{q_i'^\top k_j+q_i^\top k_j'}{\sqrt{d_{\mathrm{head}}}},
\]

\[
s_{ij}''=\frac{q_i''^\top k_j+2q_i'^\top k_j'+q_i^\top k_j''}{\sqrt{d_{\mathrm{head}}}}.
\]

For a fixed, serialized unmasked pivot \(p\), define

\[
e_j=\exp(s_j-s_p),\qquad D=\sum_{k\in U_i}e_k,
\qquad a_j=e_jD^{-1}.
\]

Subtracting a fixed pivot is an exact algebraic identity. The pivot may be selected at formal prepare from t-independent graph metadata or the exact center constants, because every pivot produces the same mathematical softmax; it may not change adaptively within the interval. Since \(e_p=1\), \(D\ge1\) structurally, which supplies a non-vacuous positive denominator certificate.

The generic exp/product/reciprocal rules are sufficient and binding. For tighter propagation, the implementation may additionally use the equivalent shared softmax recurrences

\[
\bar s'=\sum_k a_ks_k',
\qquad
a_j'=a_j(s_j'-\bar s'),
\]

\[
\bar s''=\sum_k a_ks_k'',
\qquad
V' = \sum_k a_k(s_k')^2-(\bar s')^2,
\]

\[
\boxed{a_j''=a_j\left((s_j'-\bar s')^2+s_j''-\bar s''-V'\right).}
\]

Both forms are independently sound. When both are evaluated, their interval intersection is used; an empty intersection is an implementation failure.

For values \(v_j(t)\), the head output \(o=\sum_j a_jv_j\) has

\[
o'=\sum_j(a_j'v_j+a_jv_j'),
\]

\[
\boxed{o''=\sum_j(a_j''v_j+2a_j'v_j'+a_jv_j'').}
\]

The output projection and residual addition then use §§5.4–5.5.

### 5.10 Bypass subtraction, PAT/TAR differencing, and final contrast

These are exact affine operations. If \(C_{c,b}^{(k)}\) encloses the \(k\)-th derivative for \(k\in\{0,1,2\}\), then

\[
B_c^{(k)}=C_{c,\mathrm J}^{(k)}-C_{c,\mathrm B}^{(k)},
\]

\[
\boxed{\Psi_r^{(k)}=B_{\mathrm{PAT}}^{(k)}-B_{\mathrm{TAR}}^{(k)}.}
\]

The final contrast projection is evaluated before or after the four-way subtraction according to the hash-consed graph; linearity makes the two forms equal. The implementation should project after symbolic branch collection when that gives greater exact cancellation.

## 6. Soundness theorem

### Theorem 1 — Primitive relational interval-jet soundness

Fix an admissible row \(r\), a dyadic interval \(J\subseteq[-h,h]\), and the exact reduced causal-cone DAG defined in §4. Assume:

1. every leaf constant is imported as an exact dyadic singleton or an explicitly outward input interval;
2. the only free variable enters through the affine hook controls;
3. every graph operation is one of the certified primitives in §5;
4. every denominator interval excludes zero and every required square-root/logarithm domain has a strictly positive lower bound;
5. the model is deterministic and in evaluation mode;
6. all interval operations use the directed-rounding contract in §9;
7. the dependency graph is complete.

Then the interval jet returned at every graph node satisfies the invariant in §5.1. In particular, the final triple

\[
(\Psi_{r,J}^{(0)},\Psi_{r,J}^{(1)},\Psi_{r,J}^{(2)})
\]

contains \(\Psi_r(t),\Psi_r'(t),\Psi_r''(t)\), respectively, for every \(t\in J\).

#### Proof

Proceed by induction in a topological ordering of the finite DAG. The claim holds for exact constants and affine control leaves by construction. Addition, subtraction, affine maps, and rearrangements preserve enclosure by interval isotonicity. The product and reciprocal formulas are the ordinary product and inverse derivative identities with every real operation replaced by an outward interval extension. Scalar composition follows the chain rule and sound interval extensions of \(f,f',f''\). The LayerNorm, attention, softmax, GELU, and output formulas in §5 are algebraic compositions of those certified operations, with their stated positive-domain assumptions. Exact DAG sharing and cancellation change only the representation of an algebraically identical function. Therefore each node enclosure is sound, and the final node yields the claimed enclosures. ∎

### Corollary 1 — Certified full-interval curvature bound

Let \(\mathcal P_h\) be any finite partition of \([-h,h]\). For every cell \(J\in\mathcal P_h\), let \(Q_{r,J}=\Psi_{r,J}^{(2)}\). Then

\[
\boxed{
M_{2,r}(h)=\max_{J\in\mathcal P_h}\operatorname{mag}(Q_{r,J})
}
\]

is a valid outward upper bound on

\[
\sup_{t\in[-h,h]}|\Psi_r''(t)|.
\]

This formula is binding. A maximum over point samples is not an admissible substitute.

## 7. Direct signed endpoint certificate

### 7.1 Exact endpoint identities

For \(h>0\) and any twice continuously differentiable \(\Psi_r\), Taylor's theorem in integral form gives

\[
\Psi_r(h)=\Psi_r(0)+h\Psi_r'(0)+K_{r,+}(h),
\]

\[
K_{r,+}(h)=\int_0^h(h-u)\Psi_r''(u)\,du,
\]

and

\[
\Psi_r(-h)=\Psi_r(0)-h\Psi_r'(0)+K_{r,-}(h),
\]

\[
K_{r,-}(h)=\int_{-h}^0(h+u)\Psi_r''(u)\,du.
\]

Subtracting yields the exact central-secant identity

\[
\boxed{
\Psi_r(h)-\Psi_r(-h)-2h\Psi_r'(0)
=K_{r,+}(h)-K_{r,-}(h).
}
\]

No third derivative is required.

### 7.2 Partitioned signed curvature enclosure

Let the positive half be partitioned into cells \([a_i,b_i]\subseteq[0,h]\), and the negative half into cells \([c_j,d_j]\subseteq[-h,0]\). Let

\[
Q_{r,i}^{+}\supseteq\{\Psi_r''(u):u\in[a_i,b_i]\},
\]

\[
Q_{r,j}^{-}\supseteq\{\Psi_r''(u):u\in[c_j,d_j]\}.
\]

The exact nonnegative weight integrals are

\[
w_i^+=\int_{a_i}^{b_i}(h-u)\,du
=h(b_i-a_i)-\frac{b_i^2-a_i^2}{2},
\]

\[
w_j^-=\int_{c_j}^{d_j}(h+u)\,du
=h(d_j-c_j)+\frac{d_j^2-c_j^2}{2}.
\]

Using outward intervals \(W_i^+\ni w_i^+\) and \(W_j^-\ni w_j^-\), define

\[
\boxed{
\mathcal K_{r,+}(h)=\sum_i W_i^+Q_{r,i}^+,
\qquad
\mathcal K_{r,-}(h)=\sum_j W_j^-Q_{r,j}^-.
}
\]

Because every weight is nonnegative, these sums rigorously enclose the two integrals. The official central-secant remainder is

\[
\boxed{
\mathcal K_{r,\mathrm{sec}}(h)
=\mathcal K_{r,+}(h)-\mathcal K_{r,-}(h).
}
\]

This signed construction can preserve cancellation between positive and negative curvature regions. It is the primary endpoint certificate.

### 7.3 Global \(M_2\) fallback

Corollary 1 implies

\[
|K_{r,+}(h)|\le\frac{h^2}{2}M_{2,r}(h),
\qquad
|K_{r,-}(h)|\le\frac{h^2}{2}M_{2,r}(h),
\]

\[
|\Psi_r(h)-\Psi_r(-h)-2h\Psi_r'(0)|
\le h^2M_{2,r}(h),
\]

and

\[
\left|
\frac{\Psi_r(h)-\Psi_r(-h)}{2h}-\Psi_r'(0)
\right|
\le\frac h2M_{2,r}(h).
\]

These are proof-valid but generally looser. They are reported as fallback diagnostics and may be used only when they satisfy the unchanged gate without threshold modification.

### 7.4 Certified endpoint error \(\epsilon_{\psi,r}(h)\)

Let outward singleton evaluations produce

\[
E_{r,+}\ni\Psi_r(h),\qquad
E_{r,0}\ni\Psi_r(0),\qquad
E_{r,-}\ni\Psi_r(-h),
\]

and

\[
D_{r,0}\ni\Psi_r'(0).
\]

Define direct interval residuals

\[
\mathcal B_{r,+}=E_{r,+}-E_{r,0}-hD_{r,0},
\]

\[
\mathcal B_{r,-}=E_{r,-}-E_{r,0}+hD_{r,0}.
\]

The same exact residuals are enclosed independently by the curvature intervals. Therefore define

\[
\mathcal R_{r,+}=\mathcal B_{r,+}\cap\mathcal K_{r,+},
\]

\[
\mathcal R_{r,-}=\mathcal B_{r,-}\cap\mathcal K_{r,-}.
\]

Both intersections must be nonempty. An empty intersection is `CERTIFICATE_IMPLEMENTATION_INVALID`, because two sound enclosures of the same quantity cannot be disjoint.

The binding endpoint-error scalar is

\[
\boxed{
\epsilon_{\psi,r}(h)=
\max\Bigl(
\operatorname{mag}(\mathcal R_{r,+}),
\operatorname{mag}(\mathcal R_{r,-})
\Bigr).
}
\]

The implementation must use the second display.

For auditability, every component is serialized:

1. **positive endpoint evaluation radius**
   \[
   \epsilon_{+,\mathrm{eval}}=\operatorname{rad}(E_{r,+});
   \]
2. **negative endpoint evaluation radius**
   \[
   \epsilon_{-,\mathrm{eval}}=\operatorname{rad}(E_{r,-});
   \]
3. **center evaluation radius**
   \[
   \epsilon_{0,\mathrm{eval}}=\operatorname{rad}(E_{r,0});
   \]
4. **slope evaluation contribution**
   \[
   \epsilon_{D,\mathrm{eval}}=h\operatorname{rad}(D_{r,0});
   \]
5. **direct residual centers**
   \[
   b_+=\operatorname{mid}(E_{r,+})-\operatorname{mid}(E_{r,0})-h\operatorname{mid}(D_{r,0}),
   \]
   \[
   b_-=\operatorname{mid}(E_{r,-})-\operatorname{mid}(E_{r,0})+h\operatorname{mid}(D_{r,0});
   \]
6. **direct residual radii**
   \[
   \rho_{B,+}=\epsilon_{+,\mathrm{eval}}+\epsilon_{0,\mathrm{eval}}+\epsilon_{D,\mathrm{eval}}+\rho_{+,\mathrm{arith}},
   \]
   \[
   \rho_{B,-}=\epsilon_{-,\mathrm{eval}}+\epsilon_{0,\mathrm{eval}}+\epsilon_{D,\mathrm{eval}}+\rho_{-,\mathrm{arith}},
   \]
   where \(\rho_{\pm,\mathrm{arith}}\) is the outward radius introduced by the final interval subtractions and multiplications;
7. **curvature midpoint contributions**
   \[
   k_+=\sum_i\operatorname{mid}(W_i^+Q_{r,i}^+),
   \qquad
   k_-=\sum_j\operatorname{mid}(W_j^-Q_{r,j}^-);
   \]
8. **curvature enclosure radii**
   \[
   \rho_{K,+}=\operatorname{rad}(\mathcal K_{r,+}),
   \qquad
   \rho_{K,-}=\operatorname{rad}(\mathcal K_{r,-});
   \]
9. **weight-rounding contributions**, accumulated as the change in the curvature radius when exact rational dyadic weights are replaced by their outward MPFR intervals;
10. **summation-rounding contributions**, accumulated by directed shadow sums;
11. **input-import contribution**, which is exactly zero for bit-decoded finite IEEE constants; a nonzero undocumented import uncertainty is forbidden;
12. **graph-reduction contribution**, which is exactly zero because reduction must preserve algebraic identity; an approximate graph reduction is forbidden;
13. **subdivision contribution**, which is exactly zero because the partition is a complete cover and no interpolation between samples is used;
14. **runtime-parity discrepancy**, which is diagnostic only and is not added to or substituted for \(\epsilon_{\psi,r}\).

The official value is the magnitude of the intersection intervals, not a selectively chosen empirical residual and not an unprincipled sum of whichever terms appear favorable.

### 7.5 Correlation-aware Joint Witness interval

The four branches share weights, constants, masks, and often large subgraphs. The official effect interval is therefore evaluated from the relational DAG:

\[
\mathcal I_{\Psi,r}(t)=
\mathcal I\!
\left[
(C_{\mathrm{PAT},\mathrm J}-C_{\mathrm{PAT},\mathrm B})
-(C_{\mathrm{TAR},\mathrm J}-C_{\mathrm{TAR},\mathrm B})
\right],
\]

not as the Minkowski sum of four independently computed whole-model output boxes. The distinction is deterministic dependence, not a Gaussian covariance assumption. No independence model is used.

A successful primitive witness must satisfy the unchanged P13 gate using this direct interval and the endpoint/curvature quantities above. If the direct interval contains the gate boundary, the row is `UNRESOLVED`; it is not rounded into success.

## 8. Dependency control and non-vacuity strategy

### 8.1 Why a full-network box is rejected as the primary witness

A four-run whole-network interval enclosure would repeatedly lose the fact that the branches share almost all of their computation. LayerNorm then couples every residual coordinate; attention multiplies uncertain queries, keys, values, and softmax weights; subsequent residual blocks compound the width. Although such an enclosure can remain formally sound, its width is predictably likely to dwarf the matched-bypass signal. Authorizing it as the primary path would make P13 failure almost predetermined and would confuse proof conservatism with theory failure.

The authorized primitive begins at stored controlled-hook tensors and proves only the exact downstream causal cone. It is still a certificate of the frozen causal intervention being claimed; it does not need to re-certify the upstream computation that produced constants already fixed in the row artifact.

### 8.2 Exact shared-DAG reduction

The graph builder performs the following sound reductions before interval evaluation:

1. **Hash-consing:** identical operation nodes with identical parent hashes and exact parameters are represented once.
2. **Exact affine collection:** nested affine maps and additions are collected over exact dyadic coefficients where tensor shape permits.
3. **Provenance-identity cancellation:** `x - x` is replaced by exact zero only when both references point to the same node hash.
4. **Common contrast projection:** because the final projection is linear, branch coefficients are collected before evaluation.
5. **Static-mask elimination:** causally masked attention entries are omitted exactly.
6. **Off-cone constant folding:** a subgraph with no `t` dependency is evaluated once as an exact dyadic/MPFR constant ball and shared.
7. **No approximate pruning:** magnitude, empirical gradient, sparsity score, or observed patching effect can never delete a node.

The graph manifest records the unreduced node count, reduced node count, every cancellation, and a semantic hash of both graphs. A randomly generated symbolic-equality suite and branch-by-branch high-precision parity suite must agree, but those parity checks test the reducer rather than certify the final scientific result.

### 8.3 Deterministic dyadic subdivision

The initial partition is `[-h,0] ∪ [0,h]`. Every split bisects a cell exactly at its dyadic midpoint. The splitter is deterministic and uses only proof-width information available from the current enclosures:

\[
\operatorname{priority}(J)=w(J)\,\operatorname{wid}(Q_{r,J}),
\]

where \(w(J)\) is the relevant exact curvature-kernel weight integral and \(Q_{r,J}\) encloses \(\Psi_r''\). Ties are broken by left endpoint, then depth. It may not inspect whether the current witness passes P13, the sign of the endpoint effect, or any development label.

The frozen stopping policy is:

1. stop a cell if the prescribed absolute and relative enclosure-width tolerances in the v4 protocol lock are both met;
2. otherwise bisect it;
3. stop the row as `RESOURCE_INCONCLUSIVE` if `max_depth = 24` or `max_cells = 262144` is reached;
4. never widen a scientific threshold to rescue such a row.

These are computational caps, not scientific success thresholds. Altering either cap after seeing row outcomes requires another GPTPro decision because it can change which rows resolve.

### 8.4 Centered mean-value tightening

For a cell \(J=[m-\rho,m+\rho]\), singleton balls at \(m\) may be intersected with the natural interval extension using the exact mean-value inclusions

\[
x(J)\subseteq x(m)+(J-m)x'(J),
\]

\[
x'(J)\subseteq x'(m)+(J-m)x''(J).
\]

Thus

\[
X^{(0)}\leftarrow X^{(0)}\cap
\left(X_m^{(0)}+(J-m)X^{(1)}\right),
\]

\[
X^{(1)}\leftarrow X^{(1)}\cap
\left(X_m^{(1)}+(J-m)X^{(2)}\right).
\]

An empty intersection is an implementation failure. This tightening retains the common one-dimensional variable and often removes much of the repeated-occurrence inflation without requiring a third derivative.

### 8.5 Optional Taylor-model refinement

Codex may not introduce an ad hoc Taylor model. A degree-two Taylor-model backend may be added only if it implements a proved inclusion map for every primitive, passes the same fixtures, and returns intervals contained in the interval-jet result. The interval-jet backend defined here remains mandatory and is the reference proof implementation. Adding or substituting another backend requires GPTPro review unless it is used only as an additional intersecting enclosure and cannot change a failure into success without the reference enclosure also being valid.

## 9. Floating-point and validated-numerics contract

### 9.1 Arithmetic backend

The certificate must use MPFR with correctly directed rounding. The reference implementation may use `gmpy2` only when its linked MPFR build exposes and passes explicit downward/upward rounding tests for every used arithmetic and transcendental primitive. `decimal`, `float`, NumPy, PyTorch, JAX, `mpmath`, CUDA, TF32, and ordinary double precision are not authorized for proof endpoints.

### 9.2 Required precision

- **256 bits:** local development/preflight only;
- **384 bits:** official certificate precision;
- **512 bits:** mandatory independent precision audit for every formally prepared row that would otherwise be eligible to proceed.

Let \(I_{384}\) and \(I_{512}\) be corresponding intervals after exact conversion to a common comparison precision. The audit requires

\[
I_{512}\subseteq I_{384}
\]

for every endpoint, derivative, curvature cell used by the witness, and final residual interval. Failure of nesting is `ROUNDING_IMPLEMENTATION_INVALID`. The official reported certificate remains the 384-bit enclosure; the 512-bit result is an audit. Neither can be replaced by the union after a nesting failure.

### 9.3 Exact import of constants

Each IEEE number is decoded into sign, significand integer, and base-two exponent. For normal and subnormal values alike,

\[
x=(-1)^s m2^e
\]

is inserted as an exact MPFR singleton. Signed zero is normalized only where the graph semantics make it irrelevant; its original bit pattern remains in provenance. NaN and infinity are rejected.

Constants created by TransformerLens code, including GELU coefficients, attention scaling, LayerNorm epsilon, and mask values, must be imported from the actual serialized execution graph or exact runtime bit pattern. Recomputing a nominally equivalent constant from a formula is forbidden unless the graph itself performs that computation and the same operations are certified.

### 9.4 Directed operations

Every primitive wrapper must expose `lower(...)` and `upper(...)` paths and set the MPFR rounding mode locally. A process-global mode without exception-safe restoration is forbidden. The implementation must test:

- addition, subtraction, multiplication, reciprocal, division, FMA;
- exponentials over underflow/overflow stress ranges;
- tanh and erf near zero and saturation;
- square root and inverse square root near the smallest permitted positive denominator;
- exact dyadic conversion, subnormal conversion, and signed zero;
- interval containment against rational values with known exact answers.

### 9.5 Summation

Tensor reductions use a fixed pairwise tree, serialized in the graph manifest. Lower and upper trees are evaluated separately with directed FMA. Reordering for performance, GPU reduction, multithreaded nondeterminism, and BLAS kernels whose rounding contract is not proven are forbidden in the official backend.

### 9.6 Runtime parity is not proof

The MPFR graph must be compared at selected singleton controls with the frozen TransformerLens/PyTorch implementation to detect extraction or semantic mismatch. The comparison threshold is a preregistered engineering tolerance based on the floating runtime's dtype and operation count. Passing parity does not certify the interval; failing parity invalidates the graph extraction. The discrepancy is not added as a guessed error bar and cannot rescue a witness.

## 10. Assumptions, validity conditions, and failure semantics

### 10.1 Exact assumptions

The certificate assumes:

1. the model, tokenizer, hook semantics, row inputs, donor tensors, branch definitions, and contrast are frozen and hash-verified;
2. model evaluation is deterministic, with dropout disabled and no data-dependent sampling;
3. the controlled hooks are affine functions of one real scalar \(t\);
4. sequence lengths, causal masks, token positions, and branch topology do not change on \([-h,h]\);
5. all downstream operations are smooth on the domain and are included in §5;
6. every LayerNorm has strictly positive epsilon and every inverse/log/square-root domain is certified valid;
7. no omitted cache, hook, side effect, alias mutation, or in-place operation changes a \(t\)-dependent value;
8. the final contrast is a frozen affine functional;
9. all proof arithmetic is outward rounded under the pinned MPFR environment;
10. the partition exactly covers \([-h,h]\) without gaps, overlaps of positive measure, or floating endpoints.

### 10.2 Hard invalidity

The row or implementation is invalid under any of the following:

- parent, repository, model, tokenizer, configuration, row, or artifact hash mismatch;
- any v3 confirmation identifier in the v4 pool or logs;
- non-affine control injection;
- unsupported or data-dependent graph operation;
- active dropout, stochastic kernel, KV-cache semantic mismatch, or hook-order mismatch;
- NaN, infinity, zero-crossing denominator, or invalid transcendental domain;
- incomplete causal cone;
- empty intersection between two valid enclosures of the same quantity;
- 512-bit interval not nested in the 384-bit interval;
- graph-reducer parity failure;
- direct graph/TransformerLens parity outside the frozen engineering tolerance;
- missing provenance field or non-canonical serialization;
- modification of a v3 immutable artifact.

### 10.3 Valid but inconclusive

The following do not invalidate the theorem but prevent a scientific success:

- interval contains the P13 boundary;
- curvature or endpoint interval is too wide;
- subdivision reaches a resource cap;
- full cone is too large for the fixed formal-prepare resource budget;
- a donor fails a static feasibility criterion;
- a valid certificate returns `UNRESOLVED`.

Such rows remain unresolved. They may not be relabeled null, active, success, or failure to improve a denominator.

### 10.4 Engineering diagnostic only

The following are diagnostics only:

- finite-grid maxima;
- AD agreement;
- sampled Hessians;
- empirical endpoint residuals;
- float-versus-MPFR discrepancies within tolerance;
- plots of interval width by depth;
- wall-clock timing.

None is allowed in the proof field of an artifact.

15. static cone size, memory estimate, and operation count fit the formal-prepare resource lock;
16. no output, endpoint effect, derivative sign, P13 status, development label, or confirmation information has been read to make the decision.

Failures are serialized by exact reason. Codex may not replace a failed donor with a hand-picked donor after seeing why its scientific response was weak. Replacement is allowed only through the predeclared deterministic next-ID rule and only for a provenance or engineering-invalid record, never for a valid but unresolved scientific record.

### 12.2 Outcome-blind assessment of whether P13 is plausible

The primitive witness is **plausibly capable** of satisfying P13, but success is not guaranteed and is not asserted before v4 outcomes exist.

The favorable facts are structural rather than outcome-derived:

- the proof starts at a frozen intervention hook rather than embeddings, removing upstream computation irrelevant to the causal intervention;
- PAT/TAR and joint/bypass branches are represented relationally, preserving exact common computation and cancellation;
- LayerNorm is handled with a joint structural denominator bound rather than independent coordinate normalization;
- softmax uses a fixed-pivot form with the structural denominator bound \(D\ge1\);
- the domain is one-dimensional and admits exact dyadic subdivision;
- signed curvature integration can retain cancellation that a global \(M_2\) magnitude discards.

The unfavorable facts are also structural:

- any early-layer residual intervention can make a large fraction of later tokens and heads dependent;
- second derivatives through attention include query-key interactions and softmax variance terms;
- a deep cone can remain wide even after exact cancellation;
- a valid interval can be too conservative to exclude the P13 boundary.

Accordingly, the honest ex ante prediction is:

> P13 is plausible for rows whose frozen control enters a late or moderately sized downstream cone and whose shared-DAG cancellation is substantial. It may remain unresolved for early, attention-wide cones. That distinction must emerge from preregistered formal-prepare geometry and later one-shot outcomes, not donor cherry-picking.

No probability of passing P13 is assigned. No v4 development result was used. A broad `UNRESOLVED` region would mean the chosen primitive is insufficiently sharp under the locked resources; it would not justify lowering P13.

## 13. Outcome-blind Boundary Transition experiment

The Boundary Transition remains the experimental half of GREEN v4. It is not authorized to run in this corrigendum; only its manifest, sampling code, schemas, and dry-run checks may be prepared.

### 13.1 Scientific question

The experiment asks prospectively:

> Does a proof-defined detectability margin predict a sharp transition between mechanistic interventions whose signed Joint Witness is resolvable and interventions that are indistinguishable from the certified nonlinear/measurement envelope?

The experiment is not a post hoc plot of certificate success against the same statistic used to declare success. It must separate a preregistered control variable from the binary/categorical scientific outcome.

### 13.2 New untouched universe

The v4 boundary pool must be generated from a new, committed sampling manifest. It must exclude:

- every v3 confirmation row and any row sharing a forbidden confirmation identifier;
- every v3 confirmation donor, target, token group, prompt hash, cache key, or derived pairing;
- any row manually inspected while designing v4;
- any row selected because its empirical patching or gradient response looked strong.

A deterministic cryptographic ordering is produced by

\[
\operatorname{SHA256}(\texttt{protocol\_id}\,\|\,\texttt{row\_canonical\_bytes}),
\]

and rows are consumed in that order. The pool, exclusions, and ordering are frozen before any v4 endpoint, derivative, or certificate outcome is calculated.

### 13.3 Boundary-spanning control schedule

For each feasible row, define a t-independent geometric scale

\[
h_{r,\mathrm{geom}}=
\frac{\|A^0_r\|_2+\eta_{\mathrm{scale}}}{\|D_r\|_2+\eta_{\mathrm{scale}}},
\]

where the norm locations, aggregation over controlled hooks, and exact dyadic \(\eta_{\mathrm{scale}}>0\) are frozen in the protocol lock. This scale uses only the input geometry, not a response.

The amplitude ladder is

\[
h_{r,j}=h_{r,\mathrm{geom}}2^{j/2},
\qquad j\in\{-8,-7,\ldots,8\},
\]

intersected with the already binding admissible control domain. Rows lacking the complete required ladder are assigned to the preregistered truncated-ladder stratum; they are not silently dropped. The ladder spans eight octaves in half-octave increments and is fixed before outcomes.

If the preceding v4 decision already freezes a different amplitude set, that existing set controls. The formula above is then the fallback only for newly sampled rows not covered by the earlier lock; it may not retroactively alter a frozen row. The formal-prepare artifact must resolve this precedence explicitly.

### 13.4 Outcome and independent covariates

The primary categorical outcome at \((r,j)\) is one of:

- `CERTIFIED_POSITIVE`;
- `CERTIFIED_NEGATIVE`;
- `CERTIFIED_NULL` only if the unchanged protocol contains a direct equivalence/null region and the entire interval lies inside it;
- `UNRESOLVED`;
- `INVALID`;
- `RESOURCE_INCONCLUSIVE`.

No unresolved point enters a success denominator as null or failure unless the pre-existing protocol explicitly says so.

The primary boundary coordinate is \(j/2\), fixed by design. Prespecified t-independent stratifiers are:

- downstream cone depth;
- reduced/unreduced node-count ratio;
- number of dependent attention score entries;
- minimum LayerNorm structural denominator margin;
- static softmax score-span bound derived from input/control geometry without evaluating the final contrast;
- control-direction norm and sparsity;
- hook family and layer band.

The final response magnitude, derivative, certificate width, or P13 status may not be used as a covariate for constructing the primary transition. Those quantities may appear only in secondary mechanistic analyses after the primary result is frozen.

### 13.5 Primary transition estimand and gate

Let \(Y_{rj}=1\) when the point produces a valid signed certificate satisfying every unchanged prerequisite through P13, and \(Y_{rj}=0\) when it is valid but unresolved. Invalid points are reported separately and do not enter either numerator or denominator.

The preregistered primary model is a monotone logistic mixed model

\[
\operatorname{logit}\Pr(Y_{rj}=1)
=\alpha+f(j/2)+u_r,
\]

where \(f\) is nondecreasing and represented by the fixed isotonic/logistic basis serialized in `boundary_design_lock.json`; \(u_r\) is a row random intercept. The no-transition comparator is an intercept-only model. Estimation code, convergence rules, and fallback exact-binomial analysis are locked during formal prepare.

A Boundary Transition success requires all of the following, without changing P13:

1. the simultaneous 95% lower confidence bound for success probability is at most 0.20 in at least one of the two lowest complete amplitude bins;
2. the simultaneous 95% lower confidence bound is at least 0.80 in at least one of the two highest complete amplitude bins;
3. the fitted 0.20-to-0.80 transition width is no more than two octaves;
4. the likelihood-ratio or preregistered permutation test against the no-transition model passes familywise \(\alpha=0.05\);
5. the direction replicates in every preregistered major row group, with no group showing a statistically supported reversed transition;
6. matched null controls do not show the same transition;
7. results survive the locked treatment of unresolved and resource-inconclusive points;
8. no amplitude, row, group, or confidence procedure is changed after opening outcomes.

If the preceding v4 decision specifies stricter numerical gates, those stricter gates remain binding. This corrigendum cannot lower them.

### 13.6 Simultaneous uncertainty

For binned displays, use exact binomial intervals with Holm closure across all prespecified bins and control families, or a precomputed max-statistic permutation band whose randomization seed and number of permutations are locked in formal prepare. Pointwise 95% intervals displayed as though simultaneous are forbidden.

For the monotone curve, use a simultaneous confidence band produced by a prespecified cluster bootstrap over rows with deterministic seeds and a max-deviation critical value. If the mixed model fails the frozen convergence diagnostics, the exact binned familywise analysis becomes primary; Codex may not try alternative models until one gives significance.

### 13.7 Controls and falsifiers

The formal-prepare manifest must include:

1. **zero-control:** \(D=0\), which must yield an exact zero relational witness up to outward singleton radius;
2. **sign reversal:** \(D\mapsto-D\), with the preregistered symmetry relation where the graph supports it;
3. **branch permutation:** a PAT/TAR or joint/bypass permutation that should destroy the claimed matched structure;
4. **norm-matched random direction:** drawn from a frozen seed without seeing responses;
5. **bypass-only control:** isolates whether apparent success comes from the bypass arm;
6. **synthetic planted transition:** validates power and analysis code without using model outcomes;
7. **curvature stress control:** uses a synthetically planted off-grid curvature spike to ensure the certificate, not a grid, determines resolution.

A transition shared equally by matched and null controls rejects the intended mechanism. A certificate that succeeds only after removing unresolved points rejects the preregistered analysis. A broad absence of resolvable points is a valid stop, not permission to tune.

### 13.8 Development and confirmation opening

Formal prepare ends after the pool, amplitude ladder, exclusions, schemas, code hashes, tests, and analysis plan are frozen. It must not compute \(Y_{rj}\). A later GPTPro decision is required to authorize development. Confirmation remains separately sealed even after development and requires its own one-shot opening decision.

## 14. Literature and Oral-level novelty audit

### 14.1 Audit conclusion

The closest literatures establish nearly every ingredient separately:

- causal intervention on activations and paths;
- interchange interventions and causal abstraction;
- first-order attribution/Jacobian approximations;
- circuit discovery and representation transport;
- certified output bounds for neural networks and transformers;
- Jacobian, Lipschitz, and curvature bounds;
- interval/Taylor-model reachability;
- relational/differential verification that preserves cancellation;
- simultaneous confidence procedures;
- identifiability and statistical detectability transitions.

The residual novelty is therefore **not** “we patch activations,” “we use intervals,” or “we observe a phase transition.” The narrow defensible novelty is the composition:

1. a basis-free, matched-bypass, four-branch causal functional tied to a mechanistic path claim;
2. a proof-valid, relational, exact-dyadic interval-jet certificate of that direct functional, including Transformer LayerNorm, attention, softmax, and full-interval second derivatives;
3. a signed endpoint-curvature theorem that converts the primitive into a nonlinearity-aware Joint Witness rather than an empirical linearization;
4. an outcome-blind, preregistered Boundary Transition experiment testing when the mechanistic functional becomes prospectively detectable;
5. strict separation between development, sealed confirmation, proof failure, measurement failure, and theory failure.

No primary work located through 2026-08-26 was found to combine all five in a transformer mechanistic-interpretability experiment. This is a residual novelty claim, not a claim that each mathematical tool is new.

### 14.3 What is genuinely new, and what is not

**Not new by itself:** activation patching, path patching, causal tracing, interchange intervention, Jacobian attribution, integrated gradients, interval bound propagation, Taylor remainders, Hessian bounds, relational verification, simultaneous confidence bands, or phase-transition terminology.

**Potentially new as a theorem:** a sound algorithm that certifies, over a continuous control interval in a frozen Transformer, the exact matched-bypass PAT–TAR four-branch functional and its first two derivatives, while preserving branch correlation through a shared causal-cone DAG and converting the result into a signed endpoint-error certificate.

**Potentially new as an empirical discovery:** a preregistered, outcome-blind detectability transition in which that certificate prospectively predicts when a mechanistic path effect is resolvable and transport-valid, while strong first-order and causal-patching baselines fail specifically below or near the certified boundary.

### 14.4 Exact Oral-level theorem claim

A defensible theorem statement for the paper is:

> **Certified Joint-Witness Theorem.** For any admissible frozen Transformer row whose controlled downstream causal cone is composed of the supported smooth primitives, the GREEN relational interval-jet algorithm returns outward enclosures of the exact matched-bypass PAT–TAR functional \(\Psi\), \(\Psi'\), and \(\Psi''\) on every dyadic cell. The signed curvature construction returns a valid direct enclosure of the endpoint linearization error. Therefore any P13 success obtained from those intervals is a deterministic statement about the exact dyadic frozen intervention graph, not a sampled or first-order approximation.

The theorem is stronger than an empirical patching result but narrower than complete causal abstraction or global verification of GPT-2. That scope must be explicit.

### 14.5 Exact Oral-level experimental result

The minimum experimental result capable of supporting an Oral-level claim is:

1. a one-shot boundary-spanning experiment on a newly frozen, contamination-audited row universe;
2. a sharp preregistered 0.20-to-0.80 transition within at most two octaves under simultaneous uncertainty;
3. replication across the major frozen row groups and, preferably, at least one additional model scale or architecture using the same theorem without threshold changes;
4. null, branch-permutation, random-direction, and bypass-only controls that do not reproduce the transition;
5. strong comparison to exact activation/path patching, AtP\*, integrated gradients, and at least one generic certified-bound baseline;
6. prospective evidence that the certified side of the boundary predicts a held-out mechanistic transport or intervention consequence, not merely certificate self-consistency;
7. a substantial set of cases where first-order or empirical methods are confidently misleading and the certified nonlinear envelope correctly predicts that failure;
8. sealed confirmation that repeats the preregistered pattern without donor, amplitude, or threshold adjustment.

The most compelling central claim would be:

> **Transformer path mechanisms have a measurable, certificate-defined detectability boundary: below it, empirical path/gradient evidence can be systematically non-identifying; above it, a basis-free matched-bypass Joint Witness prospectively predicts causal transport.**

### 14.6 Evidence that remains insufficient

The following would not support an Oral claim:

- theorem fixtures without real-model certificates;
- a handful of hand-selected successful rows;
- empirical agreement between AD and finite differences;
- intervals that are formally valid but nearly always vacuous;
- success obtained only by lowering P13 or removing unresolved points;
- a transition defined after plotting outcomes;
- a transition in certificate width without an independent causal/transport consequence;
- one model/task with no strong attribution or verifier baselines;
- a result equally present in random, permuted, or bypass-only controls;
- a paper whose main contribution is “rigorous error bars for activation patching” without a mechanistic discovery;
- opening or indirectly consulting the v3 confirmation set;
- cosmetic reframing of the failed v3 result.

### 14.7 Reviewer-risk verdict

The ICLR Oral trajectory remains plausible but highly conditional. The theorem is publishable only if the implementation is demonstrably sound and non-vacuous. The Oral case requires the Boundary Transition to reveal a counterintuitive, prospective limitation of standard mechanistic evidence and a transport consequence that the certificate predicts. If valid certificates remain broadly unresolved, or if simple exact path patching/AtP\* performs equally well on all prospective tests, the current Oral thesis fails even though the validated-numerics contribution may remain technically correct.
